V3 → V4 — "흥미 유발형"에서 "신청·결제 전환형"으로 재기획
가장 중요한 변화
V3가 "흥미 → 경험 → 선택"까지였다면, V4는 여기에 "왜 이 교육이어야 하는가(신뢰)"와 "실제로 얼마를 내는가(비용 구체화)", "어떻게 신청·결제하는가(절차)"를 더했습니다. 9개 섹션 → 12개 섹션으로 확장했고, TRUST & PROOF·COST & SUPPORT·APPLICATION GUIDE 3개 섹션이 새로 생겼습니다.
신뢰 근거 섹션 신설
V3에는 없던 "어떤 강의로 배우고, 무엇을 직접 해보게 될까요?"(TRUST & PROOF) 섹션을 추가했습니다. 실제 강사·강의 화면·실습 콘텐츠 자료가 아직 확정되지 않아, 모든 항목을 "삽입 예정"/"확인 필요"로 명확히 표시했습니다(가상 자료로 오인되지 않도록).
비용 안내 구체화
V3의 GOVERNMENT SUPPORT(제도 안내 중심)를 COST & SUPPORT로 바꾸고, 대표 과정 2개의 실제 훈련비를 예시 카드로 보여줍니다. 본인부담금은 여전히 미확정이라 "확인 필요"로 남겨, 임의 금액을 만들지 않았습니다.
신청 절차 독립 섹션화
V3는 FAQ 안에서 신청을 간접적으로 다뤘지만, V4는 APPLICATION GUIDE라는 5단계 독립 섹션(자격확인→과정선택→수강신청→본인부담금결제→학습시작)으로 분리했습니다.
이벤트 추적 구조(스텁)
hero_cta_click, interest_select, benefit_course_click, support_info_click, course_detail_click, application_guide_click 6개 이벤트를 window.__v4Events에 기록하는 구조만 마련했습니다. 실제 분석 도구(GA4 등)는 연결되지 않았으므로 "수집된다"고 주장하지 않습니다.
섹션별 상세 매핑과 승인 필요 항목은 docs/v3-v4-comparison.md와 docs/v4-validation.md를 확인해주세요.
V2 → V3 — "정보 전달형"에서 "전환형(실습 경험 중심)"으로 재기획
가장 중요한 변화
V2는 V1의 카피만 다듬은 버전이지만, V3는 정보 구조 자체를 다시 짰습니다. 정책·통계를 앞세우던 순서를 "직접 해보고 싶다"는 흥미 유발부터 시작해, 실습 경험 → 교구 혜택 → 비용 부담 완화 → 관심사 선택 → 과정 비교 → FAQ → 전환 순서로 재배치했습니다. 섹션 수는 V2의 13개 구성에서 V3 9개로 정리했습니다.
제외된 V1/V2 전용 콘텐츠
정책 통계 섹션(BY THE NUMBERS), 사교육 비교 섹션, 가상 학습자 영상 후기 섹션은 V3의 9개 섹션 구조에 독립 섹션으로 재사용하지 않았습니다(기획 지침에 따름). 비용 안내는 GOVERNMENT SUPPORT 섹션으로, 실습 교구 혜택은 SPECIAL BENEFIT 섹션으로 역할을 이어받았습니다.
탐색 UX
V2의 4문항 성향 퀴즈(COURSE FINDER) 대신, V3는 관심사 3가지 중 1개를 즉시 선택하는 INTEREST SELECTOR로 단순화했습니다(로그인·개인정보 입력 없음).
과정 카드 정보량
V2는 "이런 분께 추천" 한 줄만 추가했지만, V3는 과정 분류·학습경험·추천대상·핵심실습·교구제공여부·훈련시간·훈련비·본인부담금·CTA까지 9개 항목을 모든 카드에 동일하게 표시합니다.
상세페이지 CTA
상세페이지 URL이 아직 없어 V3의 모든 "과정 자세히 보기"는 href="#"가 아닌 "상세페이지 연결 준비 중" 비활성 표시로 구현했습니다.
섹션별 상세 매핑과 승인 필요 항목은 docs/change-log.md의 "V2 → V3" 표를 확인해주세요.
V1 → V2 — 카피·설득 구조 개선 (디자인 동일)
01. HERO
메인 카피를 "직접 가동시키는 미래" → "직접 만드는 미래"로 비교 검토. CTA를 "나에게 맞는 교육과정 찾기"로 바꿔 대표 CTA 역할을 하도록 하고, 온라인·실습 가치를 서브카피에 먼저 담았습니다.
08. 교육과정 선택
9개 과정 카드 전체에 "이런 분께 추천" 한 줄을 새로 추가했습니다. 과정명·시간·가격·개수는 변경하지 않았습니다.
11. 최종 CTA
"지금 수강신청하기" → "교육과정 선택하기"로 변경 — 실제 신청 화면으로 바로 연결되지 않는 버튼에는 "신청하기" 표현을 쓰지 않는다는 원칙을 적용했습니다.
전체 11개 섹션 변경 내역은 docs/change-log.md의 "V1 → V2" 표를 확인해주세요.
※ V1/V2는 PC 전용(최소 너비 1440px), V3·V4는 데스크톱·태블릿·모바일 반응형으로 제작되었습니다. 이 비교 도구의 "모바일 미리보기"는 V1/V2 화면을 축소해 참고용으로 보여주는 기능이며, V3·V4 화면은 실제 반응형 그대로 보여줍니다. 각 패널은 내부 스크롤로 독립적으로 움직입니다.
