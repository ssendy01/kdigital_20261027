# V3 → V4 기획 비교 (`docs/v3-v4-comparison.md`)

V3는 "흥미 유발 → 경험 → 관심사 선택"까지의 전환형 랜딩페이지였습니다. V4는 여기서 한 걸음 더 나아가 **"왜 지금 배워야 하는가 → 실질적 활용 가치 → 이 교육을 믿을 수 있는 근거 → 실제 비용 → 과정 선택 → 신청·결제 절차"**까지 답하는, 신청·결제 전환을 목표로 하는 페이지로 재기획했습니다.

## 항목별 비교표 (PRD §10 형식)

| 항목 | V3 | V4 | 개선 의도 |
|---|---|---|---|
| 히어로 | "배우는 기술을 넘어, 직접 만드는 미래." 계열 카피, 핵심 혜택 3개 배지 | "이제, 보는 기술에서 해보는 기술로." + "AI로 홈페이지를 만들고, 로봇을 움직이고, 내 아이디어를 결과물로." | 구매 동기(업무 활용·결과물 제작)를 서브카피에서 바로 보강 |
| 필요성 설득 | INTEREST 섹션에서 암시적으로만 전달 | WHY IT MATTERS 신규 섹션에서 "업무 활용/아이디어 구현/새로운 분야 탐색" 3가지로 명시 | 학습 필요성과 내 생활의 관련성을 직접 연결 |
| 학습 방식 | 3단계 프로세스(배우고·해보고·완성하고) 소개 | 동일 구조 유지 + "검색하며 배우는 것보다 체계적" 비교 프레이밍 추가 | 무료 콘텐츠 대비 선택 이유 제시 |
| 신뢰 근거 | 없음 | TRUST & PROOF 섹션 신설(강사·강의화면·실습콘텐츠, 현재는 플레이스홀더) | "무엇을 믿고 신청하나"에 대한 구조적 답변 마련 |
| 비용 | GOVERNMENT SUPPORT — 제도·FAQ 안내 중심 | COST & SUPPORT — 대표 과정 2개의 실제 총 훈련비를 카드로 제시, 본인부담금은 "확인 필요" | 추상적 제도 설명 → 구체적 금액 비교로 구매 판단 지원 |
| 과정 선택 | 관심사 3분류(기술 중심 라벨) | 관심사 3분류를 "목적" 중심 문장으로 재작성(A/B/C 동일 매핑) | 기술 이름보다 사용자의 목적에 맞춰 공감도 향상 |
| 신청 절차 | FAQ 안에서 간접 언급 | APPLICATION GUIDE 5단계 독립 섹션 | 결제·신청까지의 동선을 명시적으로 안내해 불안 해소 |

## 신규 구현 사항

- **12개 섹션 전체 신규 제작**(V3 파일을 복사해 고치지 않고 V4 전용 HTML/CSS/JS로 독립 작성)
- **이벤트 추적 스텁**: `hero_cta_click`, `interest_select`, `benefit_course_click`, `support_info_click`, `course_detail_click`, `application_guide_click` 6개 이벤트가 `window.__v4Events` 배열에 쌓이고 콘솔에 로그로 남습니다. 실제 GA4/GTM 등은 연결되어 있지 않으며, 연동 시 `trackEvent()` 함수 본문만 교체하면 되는 구조입니다.
- **모바일 메뉴**: V3에는 없던 햄버거 메뉴를 추가해 6개 섹션 앵커로 바로 이동할 수 있습니다.
- **TRUST & PROOF 플레이스홀더**: 강사/강의화면/실습콘텐츠 자료 미확정 상태를 "삽입 예정"으로 명확히 표시 — 실제 서비스 게시 전 교체 필요.
- **비용 예시 카드**: 대표 2개 과정(미래모빌리티 자율주행, AI로 완성하는 홈페이지)의 확정된 총 훈련비만 표기, 본인부담금은 "확인 필요"로 유지.

## V1/V2/V3 영향

V1, V2, V3 파일은 이번 작업에서 전혀 수정하지 않았습니다(`git diff origin/main -- versions/v1/ versions/v2/ versions/v3/`로 확인). `compare.html`만 V4 옵션을 추가하는 방식으로 확장했으며, 기존 V1~V3 비교 기능은 그대로 유지됩니다.
