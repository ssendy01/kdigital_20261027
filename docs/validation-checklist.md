# V3 검토 체크리스트 (`docs/validation-checklist.md`)

상태 구분: **완료** / **확인 필요** / **미완료** / **해당 없음**

---

## 14.1 기획 QA

| 항목 | 상태 | 비고 |
|---|---|---|
| 9개 섹션이 정해진 설득 순서를 따른다 | 완료 | HERO→INTEREST→LEARNING EXPERIENCE→SPECIAL BENEFIT→GOVERNMENT SUPPORT→INTEREST SELECTOR→COURSE SHOWCASE→FAQ→FINAL CTA 순서로 구현 |
| 각 섹션의 목적이 명확하다 | 완료 | 섹션별 eyebrow + 단일 헤드라인으로 역할 구분 |
| 핵심 소구점이 초반에 전달된다 | 완료 | 히어로 혜택 배지 3개(온라인/카드지원/교구제공)로 1화면 내 전달 |
| 문제 제기 메시지가 중복되지 않는다 | 완료 | V2의 정책/통계/사교육비교 섹션을 독립 재사용하지 않아 중복 제거 |
| 실제 교육과정의 차별점이 드러난다 | 완료 | 과정 카드 9필드(추천대상·핵심실습·교구여부 포함)로 차별점 노출 |
| 가상 후기가 실제 후기처럼 사용되지 않는다 | 해당 없음 | V3에는 후기 섹션을 두지 않음(V2 가상 후기 섹션 미사용) |
| 교육 혜택과 지원 조건이 정확하다 | 확인 필요 | 본인부담금·교구 지급 조건 등 미확정 수치는 "확인 필요"로 표기, 운영 자료 확정 대기 |

## 14.2 카피 QA

| 항목 | 상태 | 비고 |
|---|---|---|
| 헤드라인이 방문자 관점으로 작성되었다 | 완료 | "이제, 보는 기술에서 해보는 기술로" 등 PRD 확정 카피 그대로 적용 |
| 과도한 전문 용어를 사용하지 않는다 | 완료 | |
| 본문이 헤드라인의 의미를 뒷받침한다 | 완료 | |
| 같은 의미의 카피가 반복되지 않는다 | 완료 | 교구 혜택은 SPECIAL BENEFIT에서만, 비용은 GOVERNMENT SUPPORT에서만 다룸 |
| 취업·창업·수익을 보장하지 않는다 | 완료 | 해당 표현 없음 |
| 임의 통계와 임의 금액이 없다 | 완료 | 본인부담금 등 미확정 수치는 전부 "확인 필요"로 표기, 임의 작성 없음 |

## 14.3 CTA QA

| 항목 | 상태 | 비고 |
|---|---|---|
| 대표 CTA가 관심사 선택으로 이동한다 | 완료 | 히어로 Primary, Final CTA → `#selector` |
| 관심사 선택 결과가 실제 과정과 연결된다 | 완료 | `main.js`의 `COURSES` 객체가 실제 9개 과정과 1:1 매핑 |
| 교구 제공 필터가 정확하게 동작한다 | 완료 | `data-kit="true"` 3개 과정만 필터링되는 것을 직접 클릭 테스트로 확인 |
| 과정별 CTA가 올바른 상세페이지로 이동한다 | 미완료 | 상세페이지 URL이 아직 확정되지 않아 "상세페이지 연결 준비 중"으로 비활성 표시 — URL 확정 후 연결 필요 |
| 잘못된 URL이나 빈 링크가 없다 | 완료 | 미확정 링크는 `<a href="#">` 대신 비활성 `<div>`로 구현 |
| 최종 CTA의 목적이 명확하다 | 완료 | 버튼 1개("내 교육과정 선택하기")로 단일화 |

## 14.4 개발 QA

| 항목 | 상태 | 비고 |
|---|---|---|
| V3 HTML이 정상 렌더링된다 | 완료 | 로컬 정적 서버로 직접 확인(콘솔 오류 없음) |
| 이미지 및 CSS/JS 경로가 정확하다 | 완료 | 상대경로 `css/style.css`, `js/main.js`, `../assets/hero-visual.webp` 확인 |
| 데스크톱과 모바일에서 가로 스크롤이 없다 | 완료 | 375px 뷰포트에서 `scrollWidth === innerWidth` JS로 직접 검증 |
| 관심사 선택이 동작한다 | 완료 | TYPE B 클릭 → 추천 과정 3개 렌더링 확인 |
| 필터 상태가 올바르게 반영된다 | 완료 | "실습 교구 제공 과정" 클릭 → "3개 표시 중" + 해당 카드만 노출 확인 |
| FAQ를 키보드로 사용할 수 있다 | 완료 | 네이티브 `<details>/<summary>` 사용 |
| 모바일에서도 CTA가 잘리지 않는다 | 완료 | 1차 점검에서 상단 바 줄바꿈 겹침 버그 발견 → 수정 후 재검증 완료 |
| 콘솔 오류가 없다 | 완료 | `read_console_messages`로 확인 |
| 기존 V1/V2의 작동에 영향이 없다 | 완료 | V1/V2 파일 미수정, main 배포 화면 변경 없음 |
