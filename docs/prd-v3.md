**프로젝트명:** K-Digital Learning Experience Landing Page
**버전:** V3.0
**문서 상태:** 기획 검토 및 와이어프레임 제작용 (대표님 전달본 — 구현에 그대로 반영됨)
**최종 산출물:** HTML High-Fidelity Wireframe + GitHub 버전 비교 + 기획 검토 문서

# 1. 프로젝트 개요

## 1.1 프로젝트 배경

미라클 K-디지털 교육과정 인덱스 페이지는 현재 V1과 V2까지 HTML 와이어프레임으로 제작되어 있다.

기존 페이지는 디지털 역량 교육의 필요성, 정부 정책, AI 관련 통계, 국비지원 혜택 등을 설명하는 정보 전달 중심 구조다.

그러나 방문자가 실제로 관심을 갖는 요소인 '무엇을 해볼 수 있는가', '나도 배울 수 있는가', '어떤 혜택이 있는가' 등이 충분히 앞부분에서 전달되지 않는다.

V3는 기존 정보 중심 페이지를 고객의 학습 동기와 행동을 중심으로 재기획한다.

## 1.2 핵심 기획 콘셉트

**"이제, 보는 기술에서 해보는 기술로."**

디지털 기술을 어렵게 설명하는 대신 직접 경험할 수 있는 기술과 결과를 보여준다.

방문자가 기술에 대한 호기심을 느끼고, 학습 가능성을 확인하고, 혜택과 비용을 이해한 다음 적합한 교육과정을 선택하도록 설계한다.

### 핵심 방향

- 정책 설명보다 학습 경험을 먼저 제시한다.
- 추상적인 미래 가치보다 구체적인 학습 결과를 보여준다.
- 국비지원은 구매 결정에 대한 비용 부담을 낮추는 설득 근거로 사용한다.
- 실습 교구 제공·소장은 대상 과정의 차별화 혜택으로 강조한다.
- 방문자가 자신의 관심사에 따라 교육과정을 쉽게 발견하도록 한다.
- 인덱스 페이지의 최종 행동은 교육과정 상세페이지 방문으로 정의한다.

## 1.3 주요 목표

**Primary Goal**: 방문자가 관심 분야에 적합한 교육과정을 발견하고 해당 상세페이지로 이동하도록 유도한다.

**Secondary Goals**
1. 디지털 기술 학습에 대한 심리적 진입장벽을 낮춘다.
2. 온라인 학습의 편의성을 전달한다.
3. 직접 실습하는 교육의 가치를 인식시킨다.
4. 실습 교구 제공 대상 과정의 차별점을 전달한다.
5. 정부지원으로 교육비 부담을 줄일 수 있다는 점을 안내한다.
6. 신청 전에 발생할 수 있는 주요 의문을 해결한다.

## 1.4 이번 단계의 작업 범위

이번 단계는 최종 서비스 개발이 아닌 **대표이사 기획·카피 컨펌을 위한 와이어프레임 제작**이다. 최종 디자인 고도화, 복잡한 모션 개발, LMS 연동, 실제 신청 시스템 개발은 이번 작업 범위에서 제외한다.

# 2. 타깃 사용자 정의

### Persona A — 업무에 AI를 활용하려는 학습자
고객의 질문: "AI가 유용하다는 건 알겠는데, 실제로 내 일에 어떻게 써야 하지?"
설득 메시지: "매일 하던 일을, 새로운 방식으로."
추천 과정 분류: AI 홈페이지 제작, AI PPT, AI 업무자동화 등

### Persona B — 새로운 디지털 기술을 체험하려는 학습자
고객의 질문: "영상에서만 보던 기술을 나도 직접 다뤄볼 수 있을까?"
설득 메시지: "화면에서 보던 기술, 이번에는 내 손으로."

### Persona C — 디지털 기술을 기초부터 배우려는 학습자
고객의 질문: "전문 지식이 없어도 시작할 수 있을까?"
설득 메시지: "처음이라서 망설였다면, 기초부터 시작하세요."

주의: 실제 수강 권장 대상과 선수학습 요건은 각 과정의 공식 안내를 기준으로 표시한다.

# 3. 핵심 소구점 및 설득 우선순위

| 우선순위 | 핵심 소구점 | 고객이 느껴야 할 가치 |
|---|---|---|
| 1 | 직접 만드는 실습형 교육 | 나도 실제로 해볼 수 있겠다 |
| 2 | 100% 온라인 학습 | 시간과 장소의 부담이 적겠다 |
| 3 | 실습 교구 무상 제공·소장 | 강의 수강 후에도 실습할 수 있겠다 |
| 4 | 국민내일배움카드 지원 | 교육비 부담을 줄일 수 있겠다 |
| 5 | 관심사에 맞는 과정 선택 | 내게 적합한 교육을 찾을 수 있겠다 |

'국비지원'을 페이지 전체의 유일한 판매 포인트로 사용하지 않는다. 실습 교구 혜택은 대상 Pre-KDT 과정에만 적용하며 전체 과정에 동일 적용되는 것처럼 표현하지 않는다. '누구나 수강 가능', '완전 무료', '수강 후 취업 보장' 등 검증되지 않은 문구는 사용하지 않는다.

# 4. 사용자 설득 여정

| 단계 | 사용자 심리 | 페이지의 역할 |

# 5. 전체 페이지 정보 구조 (9개 섹션)

1. HERO — 보는 기술에서 해보는 기술로
2. INTEREST — 내가 직접 해보고 싶은 기술
3. LEARNING EXPERIENCE — 온라인 학습과 실제 실습
4. SPECIAL BENEFIT — 실습 교구 무상 제공 및 소장
5. GOVERNMENT SUPPORT — 교육비 부담 완화
6. INTEREST SELECTOR — 관심 분야 선택
7. COURSE SHOWCASE — 실제 교육과정 비교
8. FAQ — 신청 전 궁금증 해소
9. FINAL CTA — 관심 교육과정 선택 유도

기존 V2에 있던 정책 통계, 사교육 비교, 가상 학습자 후기 등은 독립 섹션으로 재사용하지 않는다.

# 6. 섹션별 상세 요구사항 (확정 카피는 docs/copy-v3.md 참고)

## SECTION 01 — HERO
Eyebrow: K-DIGITAL BASIC SKILLS TRAINING / H1: "이제, 보는 기술에서 해보는 기술로." / Sub: "AI로 만들고, 로봇을 움직이고, 아이디어를 현실로." / CTA Primary: 나에게 맞는 교육 찾기(→관심사 선택) / Secondary: 어떤 걸 배울 수 있나요?(→SECTION 02)

## SECTION 02 — INTEREST
4개 경험 카드(자율주행/3D프린팅/로봇 제어/AI 홈페이지), 실제 교구·실습 이미지가 확인되기 전까지는 아이콘형 그래픽을 사용하고 실물 사진으로 오인되지 않게 한다.

## SECTION 03 — LEARNING EXPERIENCE
배우고 → 직접 해보고 → 완성하고, 3단계 온라인+실습 학습 흐름.

## SECTION 04 — SPECIAL BENEFIT
Pre-KDT 대상 과정의 실습 교구 무상 제공·반납 없이 소장 혜택. 대상 과정에만 적용됨을 명시.

## SECTION 05 — GOVERNMENT SUPPORT
정부지원 훈련비 / 본인부담금 확인 / 지원 자격 확인 3블록. '안 쓰면 사라지는 내 돈', '무조건 무료' 등 금지 카피 사용하지 않음.

## SECTION 06 — INTEREST SELECTOR
TYPE A(실습형 기술) / TYPE B(AI 업무 활용) / TYPE C(디지털 기술 기초) 3가지 중 1개 선택 → 추천 과정 노출 → SECTION 07로 이동. 4문항 이상 성향 테스트 구현하지 않음. 로그인·개인정보 입력 요구하지 않음.

## SECTION 07 — COURSE SHOWCASE (가장 중요한 전환 섹션)
카드 필수 9개 항목: 과정 분류 / 실제 과정명 / 한줄 학습경험 카피 / 추천 대상 / 핵심 실습 내용 / 실습 교구 제공 여부 / 훈련시간 / 훈련비·본인부담금 / 상세페이지 CTA. 실제 URL이 없으면 href="#" 대신 "연결 준비 중"으로 표시.

## SECTION 08 — FAQ
5개 질문(코딩 모름/온라인 실습 방식/교구 반납/국민내일배움카드/실제 비용), `details`/`summary` 기반 구현, 키보드 접근성 고려.

## SECTION 09 — FINAL CTA
Eyebrow: YOUR NEXT STEP / H2: "어렵게만 보였던 기술, 이제 직접 해볼 차례입니다." / CTA: 내 교육과정 선택하기(하나만 강조).

*(섹션별 세부 지침·카피 원문은 사용자가 제공한 PRD 전문을 그대로 반영했으며, 본 문서는 요약 버전입니다. 전체 원문은 작업 대화 기록 및 `docs/copy-v3.md`를 함께 참고해 주세요.)*

# 7. 전체 CTA 전략

| 위치 | 문구 | 동작 |
|---|---|---|
| Hero | 나에게 맞는 교육 찾기 | 관심사 선택(SECTION 06)으로 이동 |
| Hero 보조 | 어떤 걸 배울 수 있나요? | 경험 소개(SECTION 02)로 이동 |
| 교구 혜택 | 실습 교구 제공 과정 보기 | 교구 제공 과정 필터 적용 후 SECTION 07로 이동 |
| 정부지원 | 지원 조건 확인하기 | FAQ(실제 지원 정보 안내)로 이동 |
| 관심사 선택 | 추천 과정 살펴보기 | 해당 분류로 필터된 SECTION 07로 이동 |
| 교육과정 카드 | 과정 자세히 보기 | 해당 상세페이지(URL 미확정 시 "연결 준비 중") |
| 최종 CTA | 내 교육과정 선택하기 | 관심사 선택(SECTION 06)으로 이동 |

'지금 신청하기'는 실제 신청 페이지로 연결할 때만 사용한다. 이번 V3에는 실제 신청 시스템이 없으므로 해당 문구를 사용하지 않았다.
