# V4 사실 확인 필요 항목 (`docs/v4-validation.md`)

PRD §9 "콘텐츠 사실 검증 규칙"에 따라, 확정 운영 자료가 없어 **임의로 작성하지 않고 "확인 필요"로 표시한 항목**을 모두 기록합니다. 아래 항목이 확정되는 대로 `versions/v4/index.html`에 반영해야 합니다.

## 교육과정 데이터

| 항목 | 현재 상태 | 비고 |
|---|---|---|
| 교육과정명 9개 | V2/V3 자료 그대로 사용 | 공식 운영 자료와 재대조 권장 |
| 실제 운영 과정 수 | 9개로 가정 | 현재 모집 중/종료된 과정이 있는지 재확인 필요 |
| 훈련시간 | Pre-KDT 3개 과정(41h), 실무활용 2개 과정(20h/16h)만 확정, 나머지 4개는 확인 필요 | drone/ev/automation/aiBasic |
| 총 훈련비 | Pre-KDT 3개(496,000원), 실무활용 2개(242,000원/193,600원)만 확정, 나머지 4개는 확인 필요 | 상동 |
| **본인부담금** | **전체 9개 과정 모두 확인 필요** | 정부지원 적용 후 실제 납부액 — 이번 V4에서 가장 중요하게 확정이 필요한 데이터 |
| 지원 자격(국민내일배움카드) | 일반 원칙만 기술, 세부 자격 요건 미확인 | 고용24 공식 기준과 대조 필요 |

| 상세페이지 URL | 전체 9개 과정 모두 없음 | 확정 시 `course-cta pending` → 실제 링크로 일괄 교체 필요 |

## SECTION 06 TRUST & PROOF (전면 미확정)

| 항목 | 현재 상태 |
|---|---|
| 강사명 / 전문 분야 / 경력 / 담당 과정 | 전부 확인 필요 — "강사 정보 삽입 예정" 플레이스홀더로 표시 |
| 실제 강의 화면 / 학습 콘텐츠 / 커리큘럼 구성 | 전부 확인 필요 — "실제 강의 화면 삽입 예정" |
| 실습 교구 이미지 / 실습 장면 / 결과물 | 전부 확인 필요 — "실습 콘텐츠 이미지 삽입 예정" |

> 이 섹션은 와이어프레임 전체에서 **가장 많은 실제 자료가 필요한 섹션**입니다. 대표님 확정 전까지는 반드시 플레이스홀더 상태를 유지해야 하며(실제 서비스 게시 전 가상 콘텐츠로 오인될 위험이 가장 큼), 자료 확보 전 임의 사진/이름을 넣지 않았습니다.
